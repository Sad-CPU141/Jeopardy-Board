# Picture and sound credits

Everything in `media/` is built by `tools/media.js` (`npm run media`). File names are hashes, so the
response to a clue is never visible in a file name. Licence texts are in `media/licenses/`.

## Flags (`media/i/flag-*.svg` → category "Flags")
Flag artwork from **flag-icons** by Panayiotis Lipiridis and contributors, MIT licence
(`licenses/flag-icons-MIT.txt`). Flags: JP, CA, BR, IT, KR, CH, AR, GR, JM, SE, KE, PT, NP, BT, KZ, ZA, KI, SC, BZ, KG.

## Country outlines (`media/i/shape-*.svg` → category "Country Shapes")
Drawn from **Natural Earth** data (public domain) via the **world-atlas** package (ISC licence,
`licenses/world-atlas-ISC.txt`). Some countries are cropped to their main territory so the outline
stays readable (France, Spain, Australia, Chile, Norway, New Zealand).

## Sounds (`media/a/*.mp3` → category "Guess the Sound")
Copied from the Khatfa repo's media (nothing is loaded from Khatfa at runtime):
- **Kenney** (kenney.nl), CC0: cards, door, coins, snow, knife, dice, chips
  (`licenses/kenney-*.txt`).
- **Ben Burnes / Abstraction**, CC0: scissors, pencil, ratchet, pills, papercut
  (`licenses/ben-burnes-cc0-packs.txt`).
- **Generated** tones made in code, no source recording: doorbell, horn, whistle, siren, clock,
  smoke alarm, reverse beeper, busy signal.

No music, clips, artwork or voice from any TV show is used.
